# AI Page Builder — API Reference (Frontend Integration)

**Base URL:** `https://webneststudiobackend.onrender.com`

All endpoints below require the same JWT auth already used for the rest of the site (`POST /api/auth/login` → `access_token`). There is no separate auth system for this feature — anonymous use is not supported.

```
Authorization: Bearer <access_token>
```

Missing/invalid token → `401`.

---

## 1. `POST /api/generate`

Starts a new generation thread.

**Request**
```json
{
  "prompt": "A landing page for a bakery called Sunny Crumbs, warm colors"
}
```

**Response — `200`**
```json
{
  "generation_id": "b4c6e4d1-2be1-40a0-b3a3-d0d1bd923e9c",
  "html": "<!DOCTYPE html>\n<!-- Generated by WebNest Studio AI Page Builder - webneststudio.co.in -->\n<html lang=\"en\">...full page...</html>",
  "provider_used": "gemini"
}
```

`html` is the complete, sanitized, watermarked HTML document — render it directly (e.g. in a sandboxed `<iframe srcDoc={html}>`), don't post-process it further.

`provider_used` is `"gemini"` or `"groq"` (Groq is the automatic fallback if Gemini fails/rate-limits).

---

## 2. `POST /api/generate/{generation_id}/refine`

Applies a follow-up instruction to an existing thread, keeping full history.

**Request**
```json
{
  "refinement": "make the header background dark blue"
}
```

**Response — `200`** (same shape as `/api/generate`)
```json
{
  "generation_id": "b4c6e4d1-2be1-40a0-b3a3-d0d1bd923e9c",
  "html": "<!DOCTYPE html>...full updated page...</html>",
  "provider_used": "gemini"
}
```

---

## 3. `GET /api/history`

Lists all generation threads for the logged-in user (for a history sidebar).

**Response — `200`**
```json
{
  "generations": [
    {
      "generation_id": "b4c6e4d1-2be1-40a0-b3a3-d0d1bd923e9c",
      "title": "A landing page for a bakery called Sunny Crumbs, w",
      "created_at": "2026-07-24T18:59:52.166775Z",
      "updated_at": "2026-07-24T19:01:04.582508Z",
      "message_count": 4
    },
    {
      "generation_id": "d84e993d-3e86-4498-a2a4-d4b7b3350932",
      "title": "A simple portfolio page for a photographer",
      "created_at": "2026-07-24T18:49:11.673809Z",
      "updated_at": "2026-07-24T18:49:11.673809Z",
      "message_count": 2
    }
  ]
}
```

`title` is auto-derived from the first ~50 characters of the initial prompt. Sorted by `updated_at` descending (most recently active thread first).

## 4. `GET /api/history/{generation_id}`

Full thread detail — every turn, every HTML snapshot, in order. Use this to restore a past session or let a user view/revert to an earlier version.

**Response — `200`**
```json
{
  "generation_id": "b4c6e4d1-2be1-40a0-b3a3-d0d1bd923e9c",
  "initial_prompt": "A landing page for a bakery called Sunny Crumbs, warm colors",
  "latest_html": "<!DOCTYPE html>...current version...</html>",
  "messages": [
    {
      "role": "user",
      "content": "A landing page for a bakery called Sunny Crumbs, warm colors",
      "html_snapshot": null,
      "provider_used": null,
      "created_at": "2026-07-24T18:59:52.166775Z"
    },
    {
      "role": "assistant",
      "content": "Generated page",
      "html_snapshot": "<!DOCTYPE html>...</html>",
      "provider_used": "gemini",
      "created_at": "2026-07-24T18:59:55.812004Z"
    },
    {
      "role": "user",
      "content": "make the header background dark blue",
      "html_snapshot": null,
      "provider_used": null,
      "created_at": "2026-07-24T19:01:00.331002Z"
    },
    {
      "role": "assistant",
      "content": "make the header background dark blue",
      "html_snapshot": "<!DOCTYPE html>...updated...</html>",
      "provider_used": "gemini",
      "created_at": "2026-07-24T19:01:04.582508Z"
    }
  ]
}
```

`403` if `generation_id` doesn't belong to the requesting user. `404` if it doesn't exist at all.

## 5. `GET /api/generate/limit-status`

Check remaining quota before showing/hiding the prompt box or a "X generations left" indicator. Does not consume quota.

**Response — `200`**
```json
{
  "remaining": 2,
  "limit": 5,
  "reset_at": "2026-07-24T19:49:10.142367Z"
}
```

`limit` is generations-per-hour; a refinement call counts the same as a new generation. `reset_at` is when the current hourly window rolls over.

---

## Error responses

All errors return `{"detail": "human-readable message"}` with one of these status codes:

| Status | Meaning | Where it can happen |
|---|---|---|
| `400` | `invalid_prompt` — empty or over the length limit (prompt: 500 chars, refinement: 300 chars) | generate, refine |
| `401` | Missing/invalid/expired JWT | all endpoints |
| `403` | `generation_id` exists but belongs to another user | refine, history detail |
| `404` | `generation_id` does not exist | refine, history detail |
| `422` | `prompt_rejected` — blocked by the content filter | generate, refine |
| `429` | Rate limit reached — retry after `reset_at` from limit-status | generate, refine |
| `503` | `generation_unavailable` — both Gemini and Groq failed, or the model output couldn't be validated as HTML | generate, refine |

---

## Notes for integration

- Every returned page (initial and every refinement) already includes a small fixed "Built with WebNest Studio" footer badge — this is intentional and should not be stripped client-side.
- `html` / `html_snapshot` values are full, self-contained documents (inline `<style>`/`<script>`, no external deps besides optional Google Fonts/icon CDN links) — safe to render directly, e.g. via an `<iframe srcDoc={html}>` (recommended, for style/script isolation) or a new tab/blob download.
- There's no separate "delete thread" or "rename thread" endpoint in this phase — out of scope per the current spec.
